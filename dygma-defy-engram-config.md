## Additional Layers

### Layer 1: Numbers & Symbols (Optimized)
- **Trigger**: Hold left thumb key 3
- **Purpose**: Easy access to numbers and mathematical symbols
- **Layout**: Traditional number row on home row for speed

### Layer 2: Navigation & Function Keys
- **Trigger**: Hold right thumb key 3  
- **Purpose**: Arrow keys, function keys, mouse control
- **Layout**: Arrow keys on WASD-equivalent positions

### Layer 3: Macros & Shortcuts (Optional)
- **Trigger**: Dual-function key or combo
- **Purpose**: Application-specific shortcuts

## Bazecor Configuration Steps

### 1. Download and Install Bazecor
- Get latest version: https://github.com/Dygmalab/Bazecor/releases/
- Install and connect your Dygma Defy

### 2. Create Base Layer (Layer 0)
1. Open Bazecor and connect keyboard
2. Go to "Layout" tab
3. Click each key and assign according to the mapping above
4. Pay special attention to the thumb cluster configuration

### 3. Configure Thumb Cluster
1. **Left thumb keys**: Space, Backspace, Layer1, Shift
2. **Right thumb keys**: Enter, Tab, Layer2, Ctrl
3. Test each key to ensure proper function

### 4. Set Up Layer 1 (Numbers)
1. Create new layer
2. Map numbers 1-0 to home row positions
3. Add mathematical symbols to easily accessible positions
4. Set layer trigger to left thumb key 3

### 5. Set Up Layer 2 (Navigation)
1. Create new layer  
2. Map arrow keys to comfortable positions (suggest WASD area)
3. Add function keys F1-F12
4. Set layer trigger to right thumb key 3

### 6. Configure RGB Lighting (Optional)
1. Set different colors for different layers
2. Use underglow to indicate active layer
3. Highlight home row keys for learning

## Learning Tips for Dygma Defy + Engram

### Week 1-2: Foundation
- **Focus on home row**: `h i a e , . t r s c z`
- **Use thumb cluster**: Get comfortable with space and backspace on thumbs
- **Split positioning**: Keep halves shoulder-width apart

### Week 3-4: Expansion  
- **Add top row**: `b y o u ' " d n g v q`
- **Add bottom row**: `k j x w - ? ! m l f p`
- **Layer practice**: Start using Layer 1 for numbers

### Week 5+: Optimization
- **Speed building**: Increase WPM targets in Keybr
- **Macro creation**: Add common shortcuts to Layer 3
- **Tenting**: Experiment with keyboard angle for comfort

## Troubleshooting

### Common Issues
- **Key not responding**: Check Bazecor connection and key mapping
- **Wrong character**: Verify layer is correct and key assignment matches
- **Thumb cluster confusion**: Practice with simple keys first (space, backspace)

### Bazecor Tips
- **Save configurations**: Export your layout as backup
- **Test mode**: Use Bazecor's test feature to verify key presses
- **Firmware updates**: Keep Bazecor and keyboard firmware current

## Export/Import Configuration

### Backup Your Layout
1. In Bazecor, go to "Backup & Restore"
2. Export your configuration
3. Save the file as `dygma-defy-engram-layout.json`

### Share Configuration
- The exported file can be shared with other Dygma Defy users
- Import using "Backup & Restore" → "Import"
